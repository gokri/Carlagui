# Carla GUI

A graphical user interface for the CARLA autonomous driving simulator.

## Structure

```
carla-gui/
├── src/          # Source code
├── assets/       # Images, icons, styles
└── README.md
```

## Requirements

- Python 3.8+
- pygame or tkinter (UI backend)
- CARLA Python API

## Getting Started

```bash
cd carla-gui
python src/main.py
```
